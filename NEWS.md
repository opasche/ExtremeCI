# ExtremeCI 0.2.1

* The ExtremeCI R package has been accepted for publication on the Comprehensive R Archive Network (CRAN)! It is now officially released on <https://cran.r-project.org/package=ExtremeCI>, with [doi:10.32614/CRAN.package.ExtremeCI](https://doi.org/10.32614/CRAN.package.ExtremeCI). One can now install ExtremeCI by simply calling `install.packages("ExtremeCI")` in R.
* Minor fixes in documentation links to match CRAN standards.
