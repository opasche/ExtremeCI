# GEV lower endpoint

GEV lower endpoint

## Usage

``` r
GEV_lower_endpoint(loc = 0, scale = 1, shape, ...)
```

## Arguments

- loc:

  Location parameter.

- scale:

  Scale parameter.

- shape:

  Shape parameter.

- ...:

  Unused.

## Value

The lower endpoint of the specified GEV distribution (returns `Inf` if
`shape>=0`).
