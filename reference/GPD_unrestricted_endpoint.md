# Unrestricted GPD endpoint

Unrestricted GPD endpoint

## Usage

``` r
GPD_unrestricted_endpoint(threshold = 0, scale = 1, shape, ...)
```

## Arguments

- threshold:

  GPD threshold value.

- scale:

  Scale parameter.

- shape:

  Shape parameter.

- ...:

  Unused.

## Value

The unrestricted endpoint of the specified GPD distribution (returns the
upper GPD endpoint if `shape<0`, and the lower endpoint otherwise).
