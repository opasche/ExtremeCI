# Unrestricted GEV endpoint

Unrestricted GEV endpoint

## Usage

``` r
GEV_unrestricted_endpoint(loc = 0, scale = 1, shape, ...)
```

## Arguments

- loc:

  Location parameter.

- scale:

  Scale parameter.

- shape:

  Shape parameter.

- ...:

  Unused.

## Value

The unrestricted endpoint of the specified GEV distribution (returns the
upper GEV endpoint if `shape<0`, and the lower endpoint otherwise).
