# GPD upper endpoint

GPD upper endpoint

## Usage

``` r
GPD_upper_endpoint(threshold = 0, scale = 1, shape, ...)
```

## Arguments

- threshold:

  GPD threshold value.

- scale:

  Scale parameter.

- shape:

  Shape parameter.

- ...:

  Unused.

## Value

The upper endpoint of the specified GPD distribution (returns `Inf` if
`shape>=0`).
