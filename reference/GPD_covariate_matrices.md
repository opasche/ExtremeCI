# GPD covariate matrices

Creates separate GPD covariate matrices from the main UI specification.

## Usage

``` r
GPD_covariate_matrices(
  X = NULL,
  x_rlvl = NULL,
  scale_cols = NULL,
  shape_cols = NULL,
  parametrization = c("classical", "orthogonal", "quantile", "endpoint"),
  out_param = parametrization
)
```
