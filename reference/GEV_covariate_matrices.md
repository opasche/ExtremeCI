# GEV covariate matrices

Creates separate GEV covariate matrices from the main UI specification.

## Usage

``` r
GEV_covariate_matrices(
  X = NULL,
  x_rlvl = NULL,
  loc_cols = NULL,
  scale_cols = NULL,
  shape_cols = NULL,
  parametrization = c("classical", "return_level", "endpoint"),
  out_param = parametrization
)
```
