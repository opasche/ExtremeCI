# GEV upper endpoint

GEV upper endpoint

## Usage

``` r
GEV_upper_endpoint(loc = 0, scale = 1, shape, ...)
```

## Arguments

- loc:

  Location parameter.

- scale:

  Scale parameter.

- shape:

  Shape parameter.

- ...:

  Unused.

## Value

The upper endpoint of the specified GEV distribution (returns `Inf` if
`shape>=0`).
